Big Data

Big Data Analytics on Databricks

A body of work moving my analysis skills from a single machine to a distributed environment, running SQL and machine learning on Apache Spark through Databricks.

Tools

Databricks Apache Spark Spark SQL PySpark

The problem

pandas is wonderful until the data no longer fits in memory. At that point the tools change, and so does the way you have to think about a query. This collection of notebooks was my deliberate effort to learn that shift, working through the same kinds of problems I solve locally, but on a Spark cluster.

What the work covers

The SQL notebooks translate familiar relational thinking into Spark SQL, querying distributed tables and mixing SQL cells with Python in the same notebook. The machine learning notebooks go further, training logistic regression and classification models directly on Spark and evaluating them with a confusion matrix, so the whole pipeline from query to model to evaluation runs in the cluster rather than on my laptop. The most complete of the modelling notebooks, an SMS spam classifier, grew into its own write-up in this portfolio.

Scoring test predictions with a confusion matrix

The outcome

I came out of this comfortable working where the data lives instead of dragging it to my machine first. The habits transfer directly to production analytics work, where datasets are measured in gigabytes and the question is not whether to distribute the computation but how.
