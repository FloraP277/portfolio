Linear Regression from Scratch

Every library will fit a linear regression for you in one line. This project throws the libraries away and predicts car prices with nothing but NumPy, to prove the math is understood rather than just the API.

Tools

Python NumPy pandas

The problem

The task is predicting car prices from a dataset of vehicle specifications, without touching scikit-learn. Calling model.fit tells you nothing about what happens inside it, and I wanted to be able to explain a regression from the linear algebra up, not just drive one from the API.

My approach

The heart of the project is solving the normal equation directly: form X-transpose-X, invert it, and apply it to the targets to get the weights, with a column of ones stacked onto the feature matrix so the bias term falls out of the same computation.

Everything around the solver is equally hand-made. I evaluate with a hand-written RMSE and engineer the features manually: the car's age is derived from its model year, and door counts and makes are one-hot encoded with plain comparisons instead of a library transformer.

Hand-written RMSE and manual feature engineering

The outcome

A working regression that predicts car prices, and a much better feel for what model.fit does under the hood. Having built the feature matrix, the solver, and the metric by hand once, the library versions stopped being magic. Now when a model misbehaves, I can reason about whether the problem lives in the data, the features, or the math.
