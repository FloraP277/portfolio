RESEARCH & MACHINE LEARNING PROJECTS

Predictive Maintenance of Trackless Mobile Machinery — Master’s Dissertation

Designed a pragmatic, quantitative study using 5,000 operational records containing vibration, temperature, hydraulic pressure, operating hours, and failure outcomes. Cleaned and transformed sensor data, treated missing values and outliers, conducted exploratory analysis, and compared Neural Network, Gradient Boosting, Random Forest, and Support Vector Machine models using accuracy, precision, recall, F1 score, ROC-AUC, and cross-validation. The Neural Network achieved 94.2% accuracy and 95.4% ROC-AUC; feature analysis identified hydraulic pressure and vibration as the strongest predictors of failure.
