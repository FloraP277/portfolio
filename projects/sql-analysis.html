SQL

Relational Data Analysis in T-SQL

Before the models and the clusters, there is the query. This is a set of T-SQL solutions written in SQL Server Management Studio, the foundation everything else in this portfolio sits on.

Tools

T-SQL SQL Server SSMS

The problem

Nearly every dataset I have ever been handed started life in a relational database. The ability to pull exactly the rows you need, shaped the way you need them, decides how much cleaning happens later in Python. These scripts work through a progression of query problems, each one a question posed against a relational schema.

What the work covers

The solutions range from filtering and sorting through joins across multiple tables, aggregations with grouping, and multi-part problems where the answer to one query feeds the next, up to window functions such as ROW_NUMBER and DENSE_RANK over partitions, and reshaping rows into columns with PIVOT. Everything was written and tested in SSMS against SQL Server, organized as a solution so the scripts stay reproducible.

Reshaping rows into columns with PIVOT

The outcome

A working fluency in T-SQL that shows up everywhere else in my work. The Spark SQL notebooks in my Databricks project were only straightforward because this foundation was already in place, and the data wrangling in my machine learning projects starts with knowing what a well-formed extract looks like.
