Housing Price Prediction with Random Forest

A regression project on the Kaggle housing dataset, predicting sale prices from dozens of features describing each property.

Tools

Python pandas scikit-learn Random Forest

The problem

The dataset describes homes through a mix of numeric and categorical features, from lot size and year built to neighborhood and roof material, with a sale price to predict. It is a classic regression problem with a realistic complication: the data arrives with missing values scattered across many columns, and the categorical features outnumber the numeric ones.

My approach

After loading the training and test sets, I set the Id column as the index so it could never leak into the model as a fake feature, then audited every column for missing values and data types. Missing data got handled column by column rather than with a blanket fill, since a missing garage year means something different from a missing lot frontage.

For the model I chose a Random Forest. An ensemble of decision trees handles the mix of feature types well, is robust to outliers, and gives feature importances that show which properties of a house actually drive its price.

Validating with cross-validation and MAE

The outcome

The trained forest predicts sale prices on held-out data and, through its feature importances, tells a story about the housing market: overall quality and living area dominate, while many features contribute almost nothing. That insight matters as much as the predictions, because it says where data collection effort is actually worth it.
