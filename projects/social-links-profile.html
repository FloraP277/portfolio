Social Links Profile Card

A responsive profile card built for a Frontend Mentor challenge with nothing but HTML and CSS. If parts of this portfolio look familiar after reading this page, that is no accident.

Tools

HTML CSS Flexbox Git

The problem

Frontend Mentor provides a design, mobile at 375px and desktop at 1440px, plus a style guide of colors and typography. The challenge is to reproduce it faithfully and make it responsive across the full range of screen sizes in between, including hover states for every link.

My approach

The card is a flex column: avatar, name, location, a short bio, and a stack of link buttons. Flexbox handles the centering both inside the card and on the page, a media query adjusts spacing and button width for small screens, and the hover states come straight from the design spec. The project lives in Git with a proper commit history, which was part of the exercise too.

Responsive adjustments for small screens

The outcome

A pixel-faithful, responsive card and, more importantly, the seed of this portfolio. The profile card you see on my home page and the stack of contact buttons below it are direct descendants of this design, rebuilt in this site's navy palette with light and dark themes on top.
