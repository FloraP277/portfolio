Machine Learning

Data Preprocessing Toolkit

A set of focused notebooks, each isolating one preprocessing technique on real data. Every model in this portfolio leans on the habits built here.

Tools

Python pandas scikit-learn

The problem

Preprocessing decisions tend to get made carelessly inside bigger projects, buried between the interesting parts, where a hasty fill or a default encoding can quietly distort everything downstream. So I pulled each technique into its own notebook and studied it on a real dataset, the Titanic passenger data for imputation among others, where the consequences of each choice are visible.

What the work covers

One notebook per technique: missing-value imputation with SimpleImputer, detecting and handling outliers, one-hot encoding categorical variables, binning continuous variables, log transforms for skewed distributions, and min-max scaling. Each notebook starts by looking at the data before changing it.

Checking missingness before imputing

The outcome

A personal reference library that the other projects on this site draw on, and a habit that outlasts any single notebook: check isnull().sum() and the distributions before any model sees the data. The cleaning stages of my credit risk and housing price projects are these techniques applied under pressure.
