Big Data

SMS Spam Classification with Spark ML

Thousands of text messages, some genuine and some spam, and a classifier that has to tell them apart. This project builds the entire spam filter inside Spark ML on Databricks, from raw text file to trained model.

Tools

PySpark Spark ML Databricks TF-IDF

The problem

The dataset is the SMS Spam Collection: real text messages labeled ham or spam. Text is nothing like the tidy numeric tables most classifiers expect, so before any model can learn, every message has to become a vector of numbers, and it has to happen at Spark scale rather than in pandas.

My approach

The heart of the project is a TF-IDF feature pipeline: a Tokenizer splits each message into words, a StopWordsRemover drops the noise, a CountVectorizer counts what remains, and IDF reweights the counts so that words which appear everywhere stop dominating. A StringIndexer turns the ham/spam label into a number, and a VectorAssembler stitches the features together for the model.

Spam messages also tend to be long, so I added the raw character length of each message as an extra feature before the split, then trained a logistic regression classifier on an 80/20 train-test split.

Adding message length as an extra feature

The outcome

A working spam filter whose every stage, ingestion, feature engineering, and training, runs distributed on the cluster. The project started life inside my Databricks collection and earned its own write-up because it is the most complete pipeline in it: the same shape as a production text classifier, just smaller.
