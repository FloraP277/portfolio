Machine Learning

Classical Machine Learning Survey

Before reaching for the newest model, I wanted to know the classics cold. This is a library of notebooks, one per algorithm, working through the classical machine learning toolkit on real and synthetic datasets.

Tools

Python scikit-learn NumPy matplotlib

The problem

Knowing one model is not the same as knowing machine learning. Every algorithm has a shape of problem it excels at and a failure mode it hides, and the only way to learn which is which is to work each one with your own hands. So each algorithm got its own notebook, its own dataset, and its own experiments.

What the work covers

On the supervised side: K-nearest neighbors, support vector machines with linear and RBF kernels, Naive Bayes, logistic regression and linear models for classification, ridge and lasso regression, ensemble learning, and a first artificial neural network. On the unsupervised side: K-Means, agglomerative, hierarchical, and DBSCAN clustering, Gaussian mixture models, PCA, and manifold learning. Supporting notebooks cover model evaluation, model improvement, pipelines, and feature engineering and selection.

The experiments are where the lessons live. The SVM notebook, for example, trains the same classifier on the breast cancer dataset before and after scaling the features by hand, and watches the test score jump, the same lesson about input scale that my neural network and preprocessing projects apply.

Compressing 64-dimensional digit images down to two components

The outcome

A working familiarity with the whole classical toolkit, and better judgment about which tool fits which problem. When my credit risk project needed a classifier or my housing project needed a regressor, the choice was informed by having already seen the alternatives succeed and fail on other data.
